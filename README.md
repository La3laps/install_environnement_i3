# Install i3 environnement

## Description

Installation of my i3 environnement on Ubuntu at LeCampusNumérique : taken from [TheDistroHopper/i3wm-nord](https://github.com/TheDistroHopper/i3wm-nord)

## Installation [EN]

### Prerequisites

Install i3 on Ubuntu by running :

- `sudo apt install i3`
- Clone the repo using :
  `git clone https://github.com/La3laps/install_environnement_i3.git`
- English locale or at least file system in English

### Steps

1. Log out of your session
2. Login again chosing the i3 window manager
3. `win + enter` or `alt + enter` to open a terminal
4. Find the folder "install_environnement_i3" where you cloned
5. Launch the install.sh script by running :
   `./install.sh`
6. Update your background and icons manually
7. Follow the steps and voilà !!

### Useful shortcuts

- Win + Enter: open terminal
- Win + arrow keys: switch windows
- Win + maj + arrow keys: move windows
- Win + d: open application list (rofi)
- Win + q: quit application
- For other shortcuts run : "cat ~/.config/i3/config"

## Installation [FR]

### Prérequis

Installer i3 sur Ubuntu en lançant :

- `sudo apt install i3`
- Cloner le repo git:
  `git clone https://github.com/La3laps/install_environnement_i3.git`
- Avoir ses locales en anglais de préférence ou au moins son filesystem en anglais.

### Etapes

1. Se log out/déconnecter de sa session
2. Se log in/connecter en choisissant le windows manager i3 à la connection
3. `win + enter` or `alt + enter` pour ouvrir un terminal
4. Trouver le dossier "install_environnement_i3" là où vous l'avez cloné depuis git
5. Se mettre dans le dossier et lancer le script d'installation install.sh en lançant la commande :
   `./install.sh`
6. Mettre à jour ses widgets (NordArc-Theme)  icones (NordArc) son curseur (Capitaine Cursors).
7. Suivre les étapes à l'écran et voilà !!

### Raccourçis utiles

- Win + Enter: ouvrir le terminal
- Win + arrow keys: changer de fenêtre
- Win + maj + arrow keys: bouger les fenêtres
- Win + d: ouvrir la liste d'applications (rofi)
- Win + q: quitter l'application
- Pour d'autre raccourçis utiliser : "cat ~/.config/i3/config"
